## 一、模块概述

采购管理模块是车辆进入平台的入口，由车商通过 **微信小程序** 发起采购申请，支持单车采购和批量采购两种模式。

---

## 二、采购模式

### 2.1 单车采购

- 车商在小程序中手动录入单台车辆的所有信息（数据+图片+证件）
- 一次性录入完成，适合少量采购场景
- 公共数据（车主信息、收款信息、交车信息）首台录入后自动复用到后续车辆
- 

### 2.2 批量采购

- 通过 Excel 模板批量导入多台车辆数据（文字信息）
- 要求同一卖方，一批生成一份采购合同
- 图片/证件资料采用 **两步分离** 模式：
  - **Step 1**：模板导入车辆基础数据
  - **Step 2**：在小程序中逐台或批量补充图片
- 采购单状态：`数据已导入 → 图片补充中 → 资料完整`
- 图片未补齐不允许提交审批

### 2.3 批量图片导入

批量采购时图片处理方案：

- 导入数据后，生成 **待补图片的车辆列表**（含完成进度）
- 小程序内提供逐台拍照页：按车辆逐台完成证件和照片拍摄
- **支持批量导入图片**：按VIN或车牌自动匹配，关联到对应车辆
- OCR自动识别行驶证/登记证信息并回填校验
- 每台完成后自动校验必拍项，标记为"已完成"，可跳转下一台

## 三、采购流程

```
采购申请 → 可申请额度校验 → 自动创建卖方子钱包 → 定价（逐台）
→ 采购审批 → 合同生成与签署 → 进入垫款流程
```

### 3.1 采购申请

- 车商通过小程序发起
- 录入车辆信息与卖方信息
- 单车采购：数据+图片一次性录入
- 批量采购：先导入模板数据，再补充图片

### 3.2 可申请额度校验

采购前系统自动校验可申请额度，额度不足则不允许发起采购。

**核心公式**：

```
可申请额度 = Min（可用保证金额度, 可用授信额度）
```

**最高授信额度**（保证金杠杆比 30:100）：

```
最高授信额度 = 保证金 ÷ 30 × 100
```

保证金为经销公司缴纳，不可动用，仅作为杠杆基数。

**可用保证金额度**：

```
可用保证金额度 = 保证金 - 销售亏损 - 存货占用 + 保证金变动
```

| 变量 | 计算方式 | 说明 |
|------|----------|------|
| 保证金 | 经销公司缴纳的初始保证金 | 不可动用 |
| 销售亏损 | ∑ 单台亏损金额（采购合同价 - 销售价），仅累计亏损订单，盈利订单不抵扣 | 只计亏不计赚 |
| 存货占用 | ∑（已签约未销售车辆的采购合同价）× 30% | 30%为独立参数，非杠杆比 |
| 保证金变动 | 经销公司追加缴纳 或 退还调整的累计金额 | 增减记录 |

**可用授信额度**：

```
可用授信额度 = 最高授信额度 - 已占用授信额度
已占用授信额度 = ∑ 已垫款未签注的车辆采购金额
```

签注 = 车辆转移待登记（将车辆登记转移至经销公司名下）。入库后即可办理签注，签注完成后释放对应的授信额度占用。

**数值示例**：

```
保证金 = 30万
最高授信额度 = 30 ÷ 30 × 100 = 100万

销售亏损 = 2万（某台车亏损2万）
在库车辆采购合同价合计 = 50万 → 存货占用 = 50 × 30% = 15万
保证金变动 = 0

可用保证金额度 = 30 - 2 - 15 + 0 = 13万

已垫款未签注车辆采购金额 = 60万
可用授信额度 = 100 - 60 = 40万

可申请额度 = Min(13, 40) = 13万
```

### 3.3 自动创建卖方子钱包

- 根据卖方信息调用银行接口自动开设子钱包
- 同一卖方不重复创建

### 3.4 定价

- 系统基于 **定价规则引擎** 逐台自动定价
- 可调用 **车300** 作为辅助定价工具
- 批量采购时逐台定价，累计汇总为总价
- 定价错误时支持人工修改

### 3.5 采购审批

- 单车采购：单台审批
- 批量采购：整批一次审批
- 审批节点可配置（配置中心管理）

### 3.6 合同生成与签署

- 三方签署：卖方 + 车商 + 经销公司
- 单车采购 → 一车一合同
- 批量采购 → 一批一合同（同一卖方）
- 卖方可委托他人签署（需提供委托证明材料）
- 签署方式：手写签名（小程序内完成）

## 五、数据对象关系

```
采购单（主表）
├── 车辆明细（子表，1:N）
│   ├── 车辆基础信息
│   ├── 车况信息
│   ├── 车辆图片/证件
│   └── 牌证资料（车牌、VIN、品牌型号、行驶证、登记证）
├── 卖方信息（1:1，同一卖方）
├── 委托人信息（0:1，卖方委托时）
├── 收款信息（1:1）
├── 交车信息（1:1）
├── 签名信息
├── 定价记录（1:N，逐台定价）
└── 采购合同（1:1）
```

## 六、业务规则

| 规则 | 说明 |
|------|------|
| 可申请额度校验 | Min(可用保证金额度, 可用授信额度) ≥ 采购总金额 |
| 批量同一卖方 | 批量采购要求所有车辆属于同一卖方 |
| 图片完整性 | 必拍项未完成不允许提交审批（可配置） |
| 定价逻辑 | 规则引擎逐台定价 → 人工可修改 → 累计汇总 |
| 合同粒度 | 单车→一车一合同；批量→一批一合同 |
| 委托签署 | 非车主签署时需上传委托证明材料 |
| OCR回填 | 行驶证/登记证/收款人证件/银行卡支持OCR自动识别 |

---

## 七、采购单状态流转

```
草稿 → 数据已导入(批量) → 图片补充中 → 资料完整
→ 待审批 → 审批中 → 审批通过 → 合同签署中 → 已签署
→ 进入垫款流程
```

驳回路径：`审批中 → 审批驳回 → 修改后重新提交`
