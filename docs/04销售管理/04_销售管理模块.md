# 04 销售管理模块 — 详细需求

> 版本：v1.0  
> 日期：2026-03-25  
> 关联：`00_智慧车城_需求概览.md`

---

## 一、模块概述

销售管理模块覆盖车辆从上架到销售签约的全流程。车辆需先完成上架，才可发起销售签约申请。支持单车销售和批量销售（同一买家）。

---

## 二、业务流程

```
车辆上架（填写销售价+上传车况报告）
→ 发起销售签约申请（从采购车辆列表操作）
→ 录入买家信息、付款信息
→ 销售金额确认
→ 销售签约审批
→ 买家付款
→ 进入清分流程
```

---

## 三、上架

### 3.1 上架说明

- 车辆入库且处于监管中状态后可执行上架
- 上架时需填写销售价格和上传车况报告
- 上架不需要走审批流（车况通过上传报告解决）

### 3.2 上架信息

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 零售价 | 数字(万元) | ✅ | 面向终端买家的售价 |
| 批售价 | 数字(万元) | ❌ | 面向批售/拍卖的底价 |
| 车况报告 | PDF/图片/二维码 | ✅ | 上传检测报告，替代上架审批 |

### 3.3 上架后状态

上架完成后车辆进入可销售状态，在采购车辆列表中出现"销售申请"操作入口。

---

## 四、销售签约

### 4.1 发起方式

- 在 **采购车辆列表** 中，对已上架的车辆点击"销售申请"
- 支持勾选多台车辆批量发起销售（同一买家）
- 数据流入零售系统的零售展厅应用

### 4.2 销售模式

| 模式 | 说明 |
|------|------|
| 单车销售 | 选择单台车辆发起销售签约 |
| 批量销售 | 选择多台车辆，批量导入到一个销售单，要求同一买家 |

### 4.3 销售单结构（步骤式表单）

分四步：车辆信息 → 买家信息 → 付款信息 → 签名附件

---

## 六、销售金额确认

提交销售签约前，系统弹窗确认：

| 字段 | 说明 |
|------|------|
| 销售台次 | 本次销售的车辆数量 |
| 采购合同价 | 所有车辆采购合同价合计 |
| 销售总价 | 所有车辆销售价合计 |

确认后提交，进入审批流程。

---

## 七、销售签约审批

- 审批节点可配置（通过审批中心统一管理）
- 审批人可查看采购价与销售价对比，识别亏损订单
- 审批通过后通知申请人（见消息通知模块）
- 审批驳回后可修改重新提交

---

## 八、买家付款

- 审批通过后，通知买家付款
- 买方打款至平台
- 付款到账后进入清分流程

## 十、销售单列表

### 10.1 菜单结构

左侧菜单：代经销车辆 → 采购单 / 采购车辆 / **销售单** / **销售车辆**

### 10.2 销售单状态流转

```
草稿 → 待审批 → 审批中 → 审批通过 → 待付款 → 已付款 → 清分中 → 已完成
```

驳回路径：`审批中 → 审批驳回 → 修改后重新提交`

---

## 十一、销售亏损处理

- 当销售价 < 采购合同价时，差额计入该车商的 **销售亏损**
- 销售亏损会扣减车商的可用合作款项额度
- 只计亏损订单，盈利订单不抵扣亏损（详见02_资金管理模块.md）

---

## 十二、数据对象关系

```
销售单（主表）
├── 车辆销售明细（子表，1:N）
│   ├── 车辆信息（自动带入）
│   ├── 采购合同价
│   ├── 销售价
│   └── 盈亏金额（销售价 - 合同价）
├── 买家信息（1:1，同一买家）
├── 付款人信息（1:1）
├── 签名信息
├── 附件（线下合同等）
└── 销售合同（1:1，三方签署）
```

---

## 十三、业务规则汇总

| 规则 | 说明 |
|------|------|
| 上架前提 | 车辆已入库且处于监管中 |
| 上架无需审批 | 上传车况报告即可 |
| 销售前提 | 车辆已上架 |
| 批量同一买家 | 批量销售要求所有车辆同一买家 |
| 亏损允许 | 销售价可低于合同价，审批人把控 |
| 合同三方签署 | 车商 + 买方 + 经销公司 |
| 付款人可非买家 | 付款人不是买家时需录入付款人信息 |
