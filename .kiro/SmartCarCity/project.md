# 智慧车城平台 — 技术栈与设计规范

## UI 设计规范

### 网格布局
- 功能入口图标统一使用 4 列网格布局（每行最多 4 个）
- 不足 4 个时左对齐，不要居中
- 图标区域宽度 56px，图标之间水平间距均分

### 图标规范
- 所有功能图标使用统一风格：48px 圆角方形浅色背景 + 24px 线性图标
- 背景色使用对应功能主色的 10% 透明度版本
- 角标（badge）统一为 16px 红色圆形，白色文字，定位在图标右上角 -4px 偏移

### 间距规则
- 模块标题与上一模块底部间距：24px
- 模块标题与下方内容间距：16px
- 模块标题字号：15px，颜色 #333，font-weight: 600

### 配色
- 主色：#E84D3D（红色，用于顶部栏、选中态）
- 功能图标色：采购类 #E84D3D，销售类 #4CAF50，管理类 #2196F3，工具类 #FF9800
- 背景色：#F5F5F5（页面底色），#FFFFFF（卡片底色）

### 顶部 Banner
- 使用渐变背景（从主色到主色偏暗 10%）
- 右侧放置装饰性 SVG 插画
- 圆角 12px 内边距 16px



## 一、项目信息

- 项目名称：唯车帮 / 智慧车城平台（Smart Car City）
- 项目类型：SaaS 多租户汽车经销管理系统
- 需求文档位置：`docs/` 目录下的所有 MD 文件
- 原型目标：高保真可交互原型，接近生产级 UI，可直接给开发团队参考

- 界面语言：全中文
- 数据展示：所有页面使用真实感的模拟数据填充

### 5.2 小程序端（移动端）规范

| 项 | 规范 |
|----|------|
| 设计宽度 | 375px（iPhone标准宽度） |
| 品牌主色 | #E8352E（红色） |
| 顶部导航栏 | 红色背景、白色文字居中、微信胶囊按钮 |
| 底部 TabBar | 4个Tab：首页/车源/代经销/我的 |
| TabBar选中色 | 红色（#E8352E） |
| TabBar未选中色 | 灰色（#999999） |
| 字体大小 | 标题 17px、正文 14px、辅助文字 12px |
| 间距 | 页面边距 16px、卡片间距 12px、内容间距 8px |
| 卡片样式 | 白色背景、圆角 12px、轻阴影 |
| 价格文字 | 红色（#E8352E）、加粗 |
| 快捷入口 | 圆角矩形图标 + 文字标签，一行4-5个 |
| 表单 | 使用 Ant Design Mobile 的 Form 组件 |
| 图片上传 | 使用 ImageUploader 组件 |
| 手写签名 | Canvas 签名板 |
| 步骤表单 | Steps + 底部固定按钮 |
| 列表页 | 下拉刷新 + 上拉加载更多 |

| 按钮-主要 | 红色实心按钮（#E8352E） |
| 按钮-次要 | 红色边框按钮 |

### 5.3 PC端（管理后台）规范

| 项 | 规范 |
|----|------|
| 设计宽度 | 1440px（主流显示器宽度） |
| 布局 | 左侧固定菜单（宽度 220px）+ 右侧内容区 |
| 顶栏 | 白色背景，右侧显示用户头像和名称 |
| 侧边菜单 | 深色背景，支持折叠/展开，支持多级菜单 |
| 字体大小 | 页面标题 20px、表格标题 16px、正文 14px、辅助 12px |
| 间距 | 内容区边距 24px、卡片间距 16px |
| 表格 | Ant Design Table，带斑马纹、固定表头、列排序 |
| 筛选区 | 表格上方，Form + Row/Col，支持展开/收起 |
| 操作列 | 最右列，常用操作直接展示，更多用 Dropdown |
| 弹窗表单 | 720px 或 1000px 的 Drawer/Modal |
| 状态标签 | Tag 组件，不同状态不同颜色 |
| 数据导出 | 表格右上角支持导出 Excel |
| 面包屑 | 内容区顶部 |
| 分页 | 表格底部，默认每页 20 条 |

### 5.4 状态标签颜色规范

| 状态类型 | 颜色 | 示例 |
|----------|------|------|
| 进行中/待处理 | 蓝色 blue | 待审批、待签约、监管中 |
| 成功/已完成 | 绿色 green | 审批通过、签约完成、已签注 |
| 警告/注意 | 橙色 orange | 超45天未销售、额度不足 |
| 错误/失败 | 红色 red | 审批驳回、提现失败、告警中 |
| 默认/中性 | 灰色 default | 草稿、未签注 |

### 5.5 金额显示规范

- 金额单位：万元（采购价、销售价、合同价）或 元（服务费、佣金等小额）
- 格式：千分位分隔，保留2位小数（如 ¥40,000.00）
- 车源价格：红色加粗 + "万"字
- 负数/亏损：红色字体
- 盈利：绿色字体
