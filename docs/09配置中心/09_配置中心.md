# 09 配置中心 — 详细需求

> 版本：v1.0  
> 日期：2026-03-25  
> 关联：`00_智慧车城_需求概览.md`

---

## 一、模块概述

配置中心管理平台所有可配置项，采用 **三级继承模型**：平台级（默认值）→ 经销公司级（可覆盖）→ 门店级（预留能力）。下级不配置时自动继承上级。

---

## 二、配置项清单

| 配置项 | 说明 | 建议粒度 | 默认值 |
|--------|------|----------|--------|
| 监管方案 | GPS/RFID/仅道闸/RFID+道闸/摄像头，可组合 | 经销公司级 | 全部支持 |
| 监管解除方式 | 手动发起审批 / 清分后自动解除 | 经销公司级 | 手动 |
| 清分-服务费规则 | 固定金额 / 合同填写金额 | 经销公司级 | - |
| 清分-佣金规则 | 固定金额 / 按比例 | 合同级 | - |
| 银行利息结算方式 | 按月 / 按台 | 经销公司级 | - |
| 提现方式 | 自动提现 / 人工手动 | 经销公司级 | 自动 |
| 垫款触发方式 | 手动发起 / 自动进入 | 经销公司级 | 手动 |
| 杠杆比 | 合作款项:最大额度的比例 | 平台级 | 30:100 |
| 存货占用比例 | 存货占用计算比例 | 平台级 | 30% |
| 库龄预警阈值 | 30/45/60天（可调整？） | 平台级 | 30/45/60 |
| 批售触发天数 | 库龄超过多少天触发批售 | 平台级 | 60天 |

---

## 三、配置管理界面

- 仅 **PC后台** 提供配置管理功能
- 平台管理员可配置平台级默认值
- 经销公司管理员可在其权限范围内覆盖配置
- 配置变更记录留痕（谁在什么时间改了什么）
