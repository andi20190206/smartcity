# 08 合同管理模块 — 详细需求

> 版本：v1.0  
> 日期：2026-03-25  
> 关联：`00_智慧车城_需求概览.md`

---

## 一、模块概述

合同管理模块为平台提供 **统一的合同服务**，覆盖合同生成、签署、归档、查询等全生命周期管理。采购合同和销售合同共用同一套合同管理能力。

---

## 二、合同类型

| 合同类型 | 签署方 | 触发时机 | 粒度 |
|----------|--------|----------|------|
| 采购合同 | 卖方 + 车商 + 经销公司 | 采购审批通过后 | 单车→一车一合同；批量→一批一合同（同一卖方） |
| 销售合同 | 车商 + 买方 + 经销公司 | 销售签约审批通过后 | 单车→一车一合同；批量→一批一合同（同一买家） |
| 批售合同 | 待确认 | 批售发起时 | 待确认 |

---

## 三、合同生命周期

```
合同生成（系统自动/手动创建）→ 待签署 → 签署中 → 已签署 → 归档
```

---

## 四、核心能力

### 4.1 合同生成

- 审批通过后系统自动生成合同
- 基于合同模板填充业务数据（车辆信息、金额、签约方等）

### 4.2 合同签署

| 签署方式 | 说明 |
|----------|------|
| 电子签名 | 小程序内手写签名（当前已有） |
| 委托人代签 | 卖方委托他人签署，需上传委托证明材料 |
| 线下合同上传 | 线下签署后上传扫描件/照片 |

### 4.3 合同查询与归档

- 按合同号、合同类型、签约方、时间范围等条件查询
- 合同附件（PDF/图片）归档存储
- 支持查看合同和下载

---

## 五、合同关键字段

| 字段 | 说明 |
|------|------|
| 合同号 | 系统自动生成，唯一标识 |
| 合同类型 | 采购合同/销售合同/批售合同 |
| 签约方 | 各方名称及信息 |
| 车辆清单 | 关联的车辆明细 |
| 合同金额 | 合同总金额 |
| 签约时间 | 合同签署时间 |
| 合同状态 | 待签署/签署中/已签署/已归档 |
| 合同附件 | PDF/图片 |
