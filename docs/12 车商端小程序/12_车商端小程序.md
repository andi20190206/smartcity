# 12 车商端小程序 — 详细需求

> 版本：v1.0  
> 日期：2026-03-25  
> 关联：`00_智慧车城_需求概览.md`

---

## 一、模块概述

车商端微信小程序是车商的主要操作入口（已有），覆盖采购、用车、销售等高频移动端操作。PC端作为辅助（批量导入等）。

---

## 二、功能模块

| 功能 | 说明 | 关联模块 |
|------|------|----------|
| 采购申请 | 单车录入/批量导入、图片拍照上传 | 01_采购管理 |
| 垫款申请 | 发起垫款、查看额度 | 02_资金管理 |
| 用车申请 | 发起用车、选择车辆、填写提车人信息 | 03_库存与监管 |
| 销售签约 | 发起销售、录入买家和付款信息 | 04_销售管理 |
| 合同查看 | 查看采购/销售合同 | 08_合同管理 |
| 审批（手机端） | 经销公司审批人使用，通过/驳回 | 07_审批中心 |
| 消息通知 | 接收审批结果、预警等通知 | 13_消息通知 |
| 额度查询 | 查看合作款项、可申请额度 | 02_资金管理 |

---

## 三、关键页面

### 3.1 采购相关

- 采购申请页（三步：车辆信息→车况信息→收款信息）
- 批量图片补充页（车辆列表→逐台拍照→完成进度）
- 采购单列表（待查验/待签约/签约完成/不通过/签约取消）

### 3.2 垫款相关

- 垫款发起弹窗（总金额/可申请金额/申请垫款金额）
- 额度查询页

### 3.3 销售相关

- 销售签约申请页（车辆信息→买家信息→付款信息→签名附件）
- 销售金额确认弹窗

### 3.4 用车相关

- 用车申请页
- 用车记录列表
