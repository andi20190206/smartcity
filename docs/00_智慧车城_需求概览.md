> 版本：v1.2

> 状态：架构梳理完成，逐模块细化中

---

## 一、项目概述

智慧车城平台是一个面向汽车经销行业的 **SaaS 多租户系统**，由平台方独立运营，为多个经销公司提供车辆采购、销售、定价、监管、资金管理等全链路数字化服务。

核心目标：对现有高耦合系统进行重构，实现模块化拆分、流程可配置化、资金流透明可控。

---

## 二、角色体系

| 角色 | 说明 |
|------|------|
| **平台** | 独立运营主体，提供全套系统服务，SaaS多租户 |
| **卖方** | 车辆原始持有者，可委托他人代办 |
| **车商** | 中间人，挂靠在经销公司下，通过微信小程序操作 |
| **经销公司** | 核心签约方，平台租户单位，可下挂多个车商 |
| **资方** | 提供垫款资金（银行 或 经销公司自身） |
| **买方** | 最终购车消费者 |

合同签署：采购合同（卖方+车商+经销公司三方）、销售合同（车商+买方+经销公司三方）。卖方可委托他人签署，需提供委托证明材料。

---

## 三、账户体系

依赖银行账户系统，通过银行接口自动创建。各类账户为 **平级关系**：

| 账户类型 | 归属角色 | 创建方式 |
|----------|----------|----------|
| 经销公司钱包 | 经销公司 | 入驻时创建 |
| 车商账户 | 车商 | 挂靠经销公司时创建 |
| 卖方子钱包 | 卖方 | 采购申请时自动创建 |

---

## 四、主线业务流程

```
采购申请 → 定价 → 采购审批 → 合同签署 → 垫款 → 提现至卖方
→ 车辆入库（绑定监管设备）→ 签注（车辆转移登记）→ 开始监管（库龄计时）
→ 上架（价格+检测报告）→ 销售签约 → 买家付款
→ 清分（四路同时到账）→ 监管解除（配置：手动/自动）
```

分支流程：批售/拍卖（库龄≥60天）、车商回购、用车申请、退车（待细化）。

> 各环节详细需求见独立模块文档。

## 五、资金流

### 5.1 采购资金流

- **经销公司出资**：经销公司钱包 →(垫款)→ 卖方子钱包 →(提现)→ 卖方银行卡
- **银行出资**（路径待确认）：银行→经销公司→卖方 或 银行→直接打给卖方

### 5.2 销售资金流 — 四路同时清分

| 清分项 | 接收方 | 计算规则 |
|--------|--------|----------|
| 平台服务费 | 平台 | 合同填写金额 或 固定金额 |
| 车商佣金 | 车商账户 | 合同比例 或 固定金额 |
| 车款（回垫款+利润） | 经销公司钱包 | 回垫款本金 + 利润 |
| 利息 | 银行 | 银行出资时单独结算 |

### 5.3 平台收入

服务费（每单） + 场地费/监管费（车辆放平台下属公司时，少数场景）。

## 六、配置化体系

三级继承：平台级（默认值）→ 经销公司级（可覆盖）→ 门店级（预留能力）。

| 配置项 | 说明 |
|--------|------|
| 监管方案 | 平台默认全部支持，经销公司选配（GPS/RFID/仅道闸/RFID+道闸） |
| 监管解除方式 | 手动发起审批 或 清分后自动解除 |
| 清分规则 | 服务费与佣金计算方式 |
| 提现方式 | 自动提现 或 人工手动 |
| 审批流节点 | 各环节审批节点可配 |
| 定价规则引擎 | 系统自动定价规则 |
