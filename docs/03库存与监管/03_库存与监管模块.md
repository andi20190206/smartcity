## 一、模块概述

监管系统是平台的 **独立核心能力模块**，必须与库存金融业务解耦。它既服务于平台自身的库存金融车辆，也可独立接入外部车辆进行监管。

### 1.1 解耦原则

- 监管系统作为独立服务，提供标准化的车辆监管能力
- 车辆来源不限：可来自库存金融采购流程，也可通过模板导入或接口创建
- 签注（车辆转移登记）仅限库存金融车辆，外部导入车辆无此节点
- 不同监管方案可灵活组合配置

### 1.2 车辆来源

| 来源 | 说明 | 是否有签注 |
|------|------|-----------|
| 库存金融车辆 | 从采购流程入库，有完整业务链（垫款、签注、清分） | ✅ 有 |
| 模板批量导入 | 通过导入模板直接纳入监管系统 | ❌ 无 |
| 接口创建 | 外部系统通过API接口创建监管车辆 | ❌ 无 |

## 二、监管方案

平台默认支持全部监管方式，经销公司按需选配，可组合使用：

| 监管方案 | 监管类型 | 设备 | 状态 |
|----------|----------|------|------|
| GPS定位 | 动态（移动监管） | GPS定位设备 | ✅ 已有 |
| 摄像头 | 辅助（视频监控） | 安防摄像头 | ✅ 已有 |
| RFID + PDA | 静态（固定监管） | RFID标签 + PDA手持终端 | ⏳ 待建 |
| 道闸系统 | 出入管控 | 道闸设备（需对接不同厂商） | ⏳ 待建 |

常见组合：GPS + 摄像头（当前已有）、RFID + PDA、RFID + 道闸、仅道闸（需标注监管车）。

## 四、入库流程

### 4.1 入库方式（由监管方案决定）

| 监管方案 | 入库方式 | 设备绑定 |
|----------|----------|----------|
| GPS移动监管 | 安装GPS设备后，约定入库时间+1天早9:00系统自动入库 | GPS设备ID绑定VIN |
| RFID固定监管 | PDA扫描RFID标签入库 | RFID标签绑定VIN |
| 仅道闸系统 | 道闸入库，标注监管车 | 道闸系统联动 |
| RFID + 道闸 | PDA入库 + 道闸入库叠加 | RFID + 道闸联动 |

### 4.2 特殊入库

- 支持特殊情况下的入库申请（非标准流程）
- 需走审批流程

### 4.3 外部导入入库

通过模板批量导入车辆直接进入监管系统，导入模板包含：

| 模板字段分类 | 包含字段 |
|-------------|----------|
| 车辆基础信息 | VIN、车牌、品牌车系、车型等 |
| 贷款信息 | 贷款金额、贷款日期等 |
| 监管方案 | GPS/RFID/道闸等 |
| 经销公司/所属人信息 | 归属经销公司、业务员等 |

## 五、出入库控制

### 5.1 规则（与监管类型联动）

| 监管类型 | 出库规则 |
|----------|----------|
| 静态监管（RFID/RFID+道闸） | 车辆不允许出库，道闸不放行。用车申请审批通过后方可临时出库 |
| 动态监管（GPS） | 车辆可出库，GPS持续追踪。用车申请审批后放行（可配置） |
| 仅道闸 | 需标注监管车辆，按配置的监管类型控制出入 |

## 十二、监管状态流转

```
待入库 → 入库确认 → 待监管 → 监管中 → 监管解除
```

中间状态：用车出库（临时） → 归还 → 恢复监管中

异常状态：设备离线/故障 → 告警 → 人工处理 → 恢复

## 十四、业务规则汇总

| 规则 | 说明 |
|------|------|
| 监管系统解耦 | 独立服务，不依赖库存金融业务 |
| 车辆来源多样 | 支持库存金融、模板导入、接口创建三种方式 |
| 签注仅限金融车 | 外部导入车辆无签注环节 |
| 监管方案可组合 | GPS+摄像头、RFID+PDA、RFID+道闸、仅道闸 |
| 出入库联动 | 静态监管不允许出库，动态监管GPS追踪 |
| 告警自动外呼 | 告警触发后自动外呼联系人 |
| 库龄预警 | 30/45/60天分级预警通知 |
| GPS自动盘点 | 系统自动通过GPS核实在库状态 |
| 报废车特殊处理 | 报废车电压低无法安装GPS，由监管人员执行入库，默认车辆入库 |
| 摄像头故障通知 | 摄像头掉线/故障时按仓库维度通知仓库监管人员 |
| 外呼优先级 | 按联系人等级依次外呼：1级→2级→3级 |
