# 05 清分结算模块 — 详细需求

> 版本：v1.0  
> 日期：2026-03-25  
> 关联：`00_智慧车城_需求概览.md`、`02_资金管理模块.md`

---

## 一、模块概述

清分结算模块负责在买家付款到账后，自动将销售回款按规则分配到各方账户。清分为 **全自动执行**，四路同时到账。

---

## 二、清分触发

- 触发条件：买家付款到账确认
- 触发方式：**系统自动执行**，无需人工操作
- 清分完成后触发监管解除流程（按配置：手动发起申请 或 自动解除）

---

## 三、清分规则

### 3.1 四路同时到账

一笔销售订单的回款，由平台自动拆分为四路，同时清分到各方账户：

| 清分项 | 接收方 | 计算规则 | 说明 |
|--------|--------|----------|------|
| 平台服务费 | 平台账户 | 销售合同中填写的费用金额 或 固定金额 | 按经销公司配置 |
| 车商佣金 | 车商账户 | 合同约定的比例 或 固定金额 | 按合同约定 |
| 车款（回垫款+利润） | 经销公司钱包 | 销售回款 - 服务费 - 佣金 - 利息 | 含回垫款本金 + 经销公司利润 |
| 银行利息 | 银行/资方 | 单独结算 | 仅银行出资时产生 |

### 3.2 计算方式

```
平台服务费 = 合同约定金额 或 固定金额（配置项）
车商佣金 = 合同约定比例 × 销售价 或 固定金额（配置项）
银行利息 = 单独结算（银行出资时，按月或按台结算）
车款 = 销售回款总额 - 平台服务费 - 车商佣金 - 银行利息
```

### 3.3 批量销售清分

- 批量销售单包含多台车辆，每台车独立计算清分
- 各台车的服务费、佣金按各自的销售价独立计算
- 汇总后统一执行清分

---

## 四、清分配置

| 配置项 | 说明 | 配置粒度 |
|--------|------|----------|
| 服务费计算方式 | 固定金额 / 合同填写金额 | 经销公司级或合同级 |
| 服务费金额/比例 | 具体数值 | 经销公司级 |
| 佣金计算方式 | 固定金额 / 按比例 | 合同级 |
| 佣金金额/比例 | 具体数值 | 合同级 |
| 银行利息结算方式 | 按月结算 / 按台结算 | 经销公司级 |

---

## 五、清分与额度联动

### 5.1 回垫款

- 清分中的"车款"部分包含回垫款本金
- 回垫款到账后，该车辆的垫款状态变为"已回款"
- 已回款是监管解除的前提条件

### 5.2 销售亏损

- 当销售价 < 采购合同价时，差额计入车商的销售亏损
- 销售亏损扣减车商的可用合作款项额度
- 仅累计亏损订单，盈利订单不抵扣

### 5.3 存货释放

- 车辆销售完成后，该车辆的采购合同价从存货占用中移除
- 存货占用减少 → 可用合作款项额度增加

---

## 六、银行利息结算

仅在银行出资（非经销公司自有资金）时产生：

| 结算方式 | 说明 |
|----------|------|
| 按月结算 | 经销公司与银行按月统一结算利息 |
| 按台结算 | 每台车销售完成后单独结算该车的利息 |

利息部分可在清分时同时划转给银行，也可单独周期性结算（按配置）。

---

## 七、清分状态流转

```
待清分（买家已付款）→ 清分中（系统执行中）→ 清分完成（四路到账）
```

异常路径：`清分中 → 清分失败（某路到账失败）→ 重试/人工处理`

---

## 八、清分失败处理

| 失败场景 | 处理方式 |
|----------|----------|
| 某一路账户到账失败 | 系统自动重试，重试失败后通知平台运营人员 |
| 金额计算异常 | 暂停清分，通知平台运营人员人工核查 |
| 买家付款金额与销售总价不符 | 暂停清分，通知相关方核实 |

| 字段 | 说明 |

| 清分单号 | 唯一标识 |

| 银行利息 | 清分至银行的金额（如有） |

| 清分时间 | 执行清分的时间 |

| 字段 | 说明 |
|------|------|

| 采购合同价 | |

## 十、批售回款清分

批售（拍卖/车商回购）的回款同样执行清分：

- 批售回款后，按订单实际情况计算清分
- 清分规则与正常销售一致
- 批售通常亏损概率较高，差额计入销售亏损

---

## 十一、数据对象关系

```
清分单（主表）
├── 关联销售单
├── 清分明细（按车辆，1:N）
│   ├── 各项金额计算
│   └── 盈亏记录
├── 四路到账记录
│   ├── 平台服务费到账状态
│   ├── 车商佣金到账状态
│   ├── 经销公司车款到账状态
│   └── 银行利息到账状态（如有）
└── 清分失败/重试记录
```

---

## 十二、业务规则汇总

| 规则 | 说明 |
|------|------|
| 自动触发 | 买家付款到账后系统自动执行清分 |
| 四路同时 | 服务费、佣金、车款、利息同时到账 |
| 逐台计算 | 批量销售时每台车独立计算清分金额 |
| 亏损计入 | 销售价 < 合同价的差额计入车商销售亏损 |
| 存货释放 | 销售完成后释放存货占用 |
| 触发监管解除 | 清分完成 + 垫款已回款 → 可发起或自动监管解除 |
| 批售同规则 | 批售回款按同样规则清分 |
