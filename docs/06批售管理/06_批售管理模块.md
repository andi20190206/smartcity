# 06 批售管理模块 — 详细需求

> 版本：v1.0  
> 日期：2026-03-25  
> 关联：`00_智慧车城_需求概览.md`、`05_清分结算模块.md`

---

## 一、模块概述

当车辆库龄超过60天仍未销售时，触发批售处理。批售是降低库存风险的手段，支持拍卖和车商回购两种方式。

---

## 二、批售触发

### 2.1 触发条件

- 车辆库龄（自垫款日起计算）≥ 60天
- 车辆仍处于监管中、未销售状态

### 2.2 预警机制

系统在批售前已通过消息通知分级预警（见13_消息通知模块.md）：

| 时间节点 | 通知 |
|----------|------|
| 垫款日+30天 | 超30天未销售提醒 |
| 垫款日+45天 | 超45天未销售提醒 |
| 垫款日+60天 | 超60天未销售提醒，建议立即介入 |

---

## 三、批售方式

### 3.1 拍卖（发拍至拍卖平台）

- 车辆发布到外部拍卖平台进行公开销售
- 拍卖成交后回款流入平台
- 回款按订单实际情况执行清分（同正常销售清分规则）

### 3.2 车商回购（内部回购）

- 车商自行买回车辆
- 车商支付回购款
- 回购款执行清分

---

## 四、批售流程

```
库龄≥60天 → 系统预警 → 发起批售申请
→ 选择方式（拍卖/车商回购）→ 批售审批
→ 执行批售（发拍 或 车商付款）
→ 回款到账 → 自动清分 → 监管解除
```

---

## 五、批售与清分

- 批售回款后按正常清分规则执行四路同时到账
- 批售通常以低于采购价成交，差额计入车商销售亏损
- 清分完成后可发起监管解除

---

## 六、业务规则汇总

| 规则 | 说明 |
|------|------|
| 触发条件 | 库龄≥60天未销售 |
| 两种方式 | 拍卖（外部平台）/ 车商回购（内部） |
| 清分同规则 | 回款按正常清分流程执行 |
| 亏损计入 | 批售亏损计入车商销售亏损 |
| 分级预警 | 30/45/60天分级通知 |
