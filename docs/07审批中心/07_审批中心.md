> 版本：v1.0  
> 日期：2026-03-25  
> 关联：`00_智慧车城_需求概览.md`

## 一、模块概述

审批中心是平台的 **统一审批引擎**，为所有业务模块提供可配置的审批流程服务。各业务模块不自行实现审批逻辑，统一调用审批中心。

---

## 二、接入的审批类型

| 审批类型 | 来源模块 | 说明 |
|----------|----------|------|
| 采购审批 | 采购管理 | 单车审批 / 批量整批审批 |
| 垫款审批 | 资金管理 | 资方为银行时可能有多个审批节点 |
| 上架审批 | 销售管理 | 当前不需要审批，但保留配置能力 |
| 销售签约审批 | 销售管理 | |
| 监管解除审批 | 库存与监管 | 手动模式时需审批 |
| 用车审批 | 库存与监管 | 经销公司或资方审批 |
| 合作款项变动审核 | 资金管理 | 平台审核 |
| 告警处理审批 | 库存与监管 | 告警处理结果审批 |
| 批售审批 | 批售管理 | 待确认是否需要 |

## 三、核心能力

### 3.1 审批流配置

- 每种审批类型可独立配置审批节点
- 支持多级审批（串行）
- 审批节点按 **经销公司级别** 配置（不同经销公司可有不同审批流）
- 支持指定审批人 或 按角色指定

### 3.2 审批操作

| 操作 | 说明 |
|------|------|
| 通过 | 审批通过，流转至下一节点或完成 |
| 驳回 | 审批驳回，退回给申请人修改后重新提交 |
| 转交 | 转交给其他审批人处理 |

### 3.3 多端支持

| 端 | 能力 |
|------|------|
| PC后台 | 完整的审批管理、审批流配置、审批记录查询 |
| 手机端 | 审批操作（通过/驳回）、审批待办列表 |

### 3.4 审批通知

- 新审批待办时通知审批人（企微/短信）
- 审批结果通知申请人（详见13_消息通知模块.md）

## 四、审批记录

| 字段 | 说明 |
|------|------|
| 审批单号 | 唯一标识 |
| 审批类型 | 采购/垫款/销售等 |
| 关联业务单号 | 关联的采购单/销售单等 |
| 申请人 | 发起审批的人 |
| 当前审批节点 | 当前处于哪个审批环节 |
| 审批人 | 各节点审批人 |
| 审批状态 | 待审批/审批中/已通过/已驳回 |
| 审批意见 | 每个节点的审批意见 |
| 审批时间 | 各节点审批时间 |

## 五、待确认事项

| 序号 | 事项 | 状态 |
|------|------|------|
| 1 | 是否需要支持并行审批（会签） | ⏳ 待确认 |
| 2 | 是否需要支持条件分支（金额>X走A审批人，否则走B） | ⏳ 待确认 |
| 3 | 审批超时自动提醒/自动通过的机制 | ⏳ 待确认 |
| 4 | 审批流变更后对已发起审批的影响 | ⏳ 待确认 |
