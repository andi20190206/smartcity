# 10 设备管理模块 — 详细需求

> 版本：v1.0  
> 日期：2026-03-25  
> 关联：`03_库存与监管模块.md`

---

## 一、模块概述

设备管理模块管理平台所有监管相关的硬件设备，包括设备台账、绑定关系、状态监控、转移和异常处理。

---

## 二、设备类型

| 设备 | 用途 | 状态 |
|------|------|------|
| GPS/OBD定位设备 | 移动监管，车辆定位追踪 | ✅ 已有 |
| 摄像头 | 视频监控，辅助监管 | ✅ 已有 |
| RFID标签 | 固定监管，车辆身份识别 | ⏳ 待建 |
| PDA手持终端 | 配合RFID扫描入库/盘点 | ⏳ 待建 |
| 道闸设备 | 出入口管控 | ⏳ 待建 |

---

## 三、设备台账

### 3.1 列表字段

| 字段 | 说明 |
|------|------|
| 设备编号 | 设备唯一标识（如GPS的IMEI号） |
| 设备类型 | GPS/摄像头/RFID/PDA/道闸 |
| 归属人员 | 当前管理人员 |
| 手机号 | 管理人员联系方式 |
| 设备状态 | 在线/离线/故障 |
| 绑定车辆 | 当前绑定的车辆VIN（如有） |

### 3.2 操作

| 操作 | 说明 |
|------|------|
| 转移 | 单个设备转移给其他管理人员 |
| 批量转移 | 多个设备批量转移 |
| 绑定/解绑车辆 | 将设备与车辆VIN关联或解除 |

---

## 四、设备异常处理

- 设备离线/故障时系统产生告警（关联告警管理）
- 通知管理人员进行更换或维修
- 异常期间车辆监管状态标记为异常

---

## 五、道闸对接

- 道闸设备需对接不同厂商的系统
- 各厂商接口协议不同，需要适配层
- 道闸对接规范待细化
